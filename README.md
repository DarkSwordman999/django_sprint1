# Django Sprint 1 - Blogicum

## Описание
Учебный проект на Django. Блог-платформа для публикации постов.

## Технологии
- Django
- Python
- SQLite
- HTML/CSS/Bootstrap

## Структура
- `html/` - статические HTML-шаблоны
- `tests/` - тесты для проверки функционала
- `requirements.txt` - зависимости проекта

## Функционал (в разработке)
- Отображение списка постов
- Просмотр отдельного поста
- Категории постов
- Статические страницы "О проекте" и "Правила"

## Запуск
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
